# Generation 只产出局势，不产出规则

Run 开局的 Generation 决定这一局有哪几个 Faction、它们因为什么结仇、各自想要什么；它不生成卡牌、数值或判定规则——那些在所有 Run 中固定。

写下这条是因为"让 AI 生成卡牌"是 AI 游戏最容易被期待的功能，未来一定有人问为什么不做。答案：生成的卡无法平衡，而且会逼玩家每局重读全部卡面文本，这是构筑类 roguelike 的死穴。玩家必须能跨 Run 积累对卡池的理解，变化应该发生在局势上，不是规则上。

## Consequences

卡池是固定资产，可以像传统卡牌游戏一样被设计、平衡和记忆。Generation 的产物只喂给 Agent 的目标系统和叙事层。
