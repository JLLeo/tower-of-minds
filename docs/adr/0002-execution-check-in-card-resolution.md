# 卡牌结算中插入 Execution Check

Tower of Minds 不是纯回合制卡牌游戏：每个 Card Type 绑定一种即时操作判定（盾=格挡时机、攻=节奏连击、法术=蓄力），结果分 Miss / Good / Perfect 三档，决定该次结算的强度。选择这种混合形态，是因为纯回合制里玩家的手上功夫无处安放，而这正是让"打出这张牌"产生重量的地方。

每回合最多触发一次判定，Miss 只打折不反噬——否则"一回合连打七张"的构筑高潮会变成折磨，Run 时长也会失控。

## Consequences

三种原型共用**一条**判定规则：spec 给出若干个目标时刻，玩家在每个时刻各按一次，
按得多准决定档位。手感的差别全部来自「按几次、按在哪」，而不是三段各写一套判分逻辑——
否则三种手感各自漂移，`steady` / `focus` / `reflex` 也没法一次性作用于全部三种。

由此来的一条硬约束：**容差不能宽到把相邻的拍子连成一片**。节奏连击的三拍只隔窗口的
0.25，容差一旦超过一半拍距，「跟上拍子」就退化成「窗口里随便按三下」。所以容差是每个
原型自己的参数，不是全局常量。

引擎不能是纯粹的回合序列：结算过程必须能挂起、等待一段实时输入、再继续。这条约束会一路影响状态机和存档/回放的设计。
