# LLM 只在固定 Atom 表内组合，不发明规则

> 修订于 Fusion / Mutation 引入时。原标题为「Generation 只产出局势，不产出规则」，
> 原结论过严：它禁止了 LLM 参与任何规则产出，而 Fusion 需要它参与。现在把禁令
> 换成一条边界。

LLM 可以**组合** Atom，永远不能**发明** Atom。具体来说：

- Run 开局的 Generation 只产出局势——这座塔叫什么、Faction 因为什么结仇、各自的诉求。
  它不碰 Card，也**不碰名册的机械身份**：Faction 的 id 是固定的。Base Card 按 id 分组，
  凭空多出一个 id 就等于凭空多出一套牌，那正是这条边界要挡住的事。变的只有名字、
  脾气、诉求与那条过节。
- Fusion 时，Agent 决定超出上限该丢哪个 Atom、新 Card 叫什么；Mutation 时，它从固定的
  Forbidden Atom 表里挑一个。**Atom 的效果与权重、费用公式、Atom 上限，全部是引擎的
  固定资产。**

原来的绝对禁令是为了保住一件事：玩家必须能跨 Run 积累对规则的理解，否则每局都要重做
一次阅读理解，这是构筑类 roguelike 的死穴。这条边界同样保住了它——Atom 表是固定的、
可背的，玩家看到一张没见过的融合卡，读的是它由哪些已知 Atom 组成，而不是一段新规则。

同时它买到了原禁令买不到的东西：**同样两张牌，找不同 Faction 融，会得到不同的牌**。
取舍与命名出自那个派系的性格，于是融合既可预测（费用与强度算得出）又有惊喜（保留了什么
取决于你在跟谁打交道）。

## Consequences

- Atom 表是需要平衡的核心资产，它的规模决定了这个游戏的内容上限——Base Card 很少，
  多样性全部由组合长出来。
- 任何"让 LLM 生成一个新效果"的提议都越过了这条线，无论它看起来多小。
- 校验因此是必需的：引擎必须确认 Agent 挑的 Atom 确实在表内、提到的 Faction id 确实
  在名册里，非法即按确定性规则回退。
- 名字是生成的，所以**任何写死了派系名的内容都是 bug**。Combatant 模板只存这个人干
  什么（弓手、斥候、执刑官），派系那半截由这一局的名册来填。
