# Faction 名册是 Tower 级别的，不是每层生成

一个 Run 的 Faction 名册由开局 Generation 一次定死（切片阶段 2 个），整座 Tower 通用；每个 Floor 出现的 Agent 都从这份名册里来。

这条看起来像是限制了内容多样性——每层来一批全新势力显然更"丰富"。但 Standing、Memory 和 Favor 三个系统全部依赖跨 Floor 的累积：如果三层的派系在五层不再出现，玩家在三层做的一切都没有对象可以兑现，站队这个动词会当场失去意义。多样性应该来自派系之间的**关系**每局不同，而不是派系本身每层换人。

## Consequences

Generation 的输出必须一次性给出整局的派系格局。为某一层单独生成新势力是破坏性改动，不是内容扩充。
