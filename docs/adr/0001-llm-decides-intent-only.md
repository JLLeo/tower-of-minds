# LLM 只在意图层决策，规则由确定性引擎裁决

每回合由引擎算出 Agent 的合法动作集，LLM 只负责从中选一个 Intent 并给出台词；它不能生成规则之外的结果、数值或效果。这样做是因为 roguelike 的核心快感是玩家在反复死亡中学会规则——只要 LLM 能改结果，规则就既不可学也不可平衡，玩家会退化成"跟 AI 讲道理"而不是钻研构筑。

## Considered Options

- **LLM 直接生成结果**（它描述发生了什么，引擎照做）——被拒绝：规则不可学，且无法做数值平衡。
- **混合**（常规回合走意图层，叙事时刻允许生成新卡/事件）——被拒绝：生成能力已经全部收进 Run 开局的 Generation，运行时不再需要第二个入口。

## Consequences

LLM 超时或失败时，引擎可以直接退回一个启发式 Intent，Run 不会中断。可玩性不依赖模型可用性。
