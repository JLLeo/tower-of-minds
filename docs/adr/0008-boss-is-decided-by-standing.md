# Boss 由 Standing 决定，且 Boss 是 Agent

塔顶等待玩家的不是一个固定的最终对手，而是**玩家 Standing 最低的那个 Faction 的首领**；玩家的盟友可能作为援军参战，而如果所有 Faction 的 Standing 都为负，塔顶就是所有人一起上。Boss 由 LLM 驱动 Intent，但它的牌组和能力是固定的、可背下来的。

两条合起来是这个设计的收口：难度不再是一条外部曲线，而是玩家前三层每一次站队自己填的期末试卷——而且是**可理解的**难度（我知道我为什么要面对他）。爽感来自"我知道它有什么牌、我为它做了准备"，难度来自"它这次的选择针对了我的构筑"。

## Considered Options

- **固定塔主**——被拒绝：整个 Faction 系统在最该兑现的一刻失效。
- **由 Generation 生成 Boss**——被拒绝：违反 ADR-0005，且 Boss 是全局最需要手工平衡的一场。
- **完全脚本化的 Boss**——被拒绝：会让 Boss 成为整局唯一没有 AI 的部分，最该有戏的地方反而最死板。
- **能力也临场发挥的 Boss**——被拒绝：不可学等于不可准备，产出的是挫败感而不是难度。

## Consequences

Boss 不能在 Run 开始时就确定，必须在进入顶层时根据当时的 Standing 结算出来。每个 Faction 都需要一个可用作 Boss 的首领和一套固定牌组。
