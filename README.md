# Tower of Minds

一款卡牌构筑 roguelike，塔里的每一派都由一个大语言模型驱动。

爬 5 个普通楼层加 1 场首领战。每一层站着两个互相敌对的派系——**它们之间也在打**。
你集火谁、放过谁，本身就是站队，不需要另外的表态系统。塔顶坐着你 Standing 最低的
那一派的首领：难度是你自己一路填出来的期末试卷。

派系记得你做过什么。它记得你在它面前打出过哪些牌，并在层间**用它见过的牌给自己组牌**——
所以藏牌是一个真实可用的策略，代价是那几回合打得更难受。

## 跑起来

```bash
npm install
# 把 .env.example 复制成 .env，填入 DEEPSEEK_API_KEY
npm run dev
```

打开终端里给出的地址即可。key 只留在 Node 侧：浏览器打到 vite 的 `/api/llm` 中间件，
前端包里没有它。

没有 key 也能玩：每一种模型决策都有确定性回退，超时就走回退，Run 照常推进——只是塔里
的人会显得木一些。

## 玩法

- **进塔前**从已解锁的 Base Card 里组一副 Loadout，**只能取自一个派系**。你带着谁的牌
  进塔，是你的第一次表态，而它可能和你在塔里的站队打架。
- **打牌**时部分卡会插入一次即时判定（每回合最多一次）：盾牌是格挡时机（按一下），
  攻击是节奏连击（跟着拍子按三下），法术是蓄力（按一下起手，撑住，快到头再按一下）。
  分 Miss / Good / Perfect 三档，Miss 只打折不反噬。空格或回车。
- **清完一层**，你偏袒过的那一派给报酬。同向站队两次之后，它给的不再是一张牌，而是
  一次 **Fusion**：把新牌和你牌库里一张的 Atom 合并、按权重重算费用。超过 4 个 Atom
  必须丢一个——丢哪个、新牌叫什么，由**那个派系的 Agent** 决定。同样两张牌，找不同派系
  融，结果不同。
- 也可以选择不丢弃而**过载**，赌一次 **Mutation**：产物至少含一个禁忌 Atom，更强更便宜，
  代价写在牌面上。这是这个系统里唯一一次赌。
- 跨局只有 **Unlock Ledger** 持久（存在 `localStorage`）。融合与突变的产物永远留在产生
  它们的那一局。

## 命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 本地开发服务器 |
| `npm test` | headless 跑完整测试套件 |
| `npm run typecheck` | 只做类型检查 |
| `npm run build` | 类型检查 + 打包 |
| `npm run smoke -- [次数]` | **手动** smoke：用真实供应商跑一遍四种决策，报连通性、延迟与合法率 |

`npm run smoke` 要花钱、要网络、结果不确定，所以它不在测试套件里。它存在的目的是回答
一个只有实测能回答的问题：回合预算成不成立。

## 代码结构

```
src/engine/     纯函数引擎。不联网、不读时钟、不掷骰——时间和随机都从外面进来
src/llm/        供应商适配器与 prompt。换供应商是改这里，不是改引擎
src/ui/         无状态渲染层。要判断的地方一律问 engine 导出的查询函数
scripts/        手动 smoke
```

两条贯穿全局的约束：

1. **引擎先算出合法集，模型只从中选。** 越界的返回一律拒绝并按确定性规则回退，Run 继续。
   每一种决策（战斗 Intent、融合取舍、层间构筑、开局局势）都走同一条
   suspend → validate → fallback 管道。
2. **唯一的测试 seam 是引擎的 Run 级公开接口**（`startRun` / `applyInput`）。测试注入
   脚本化的假 provider、脚本化的输入时刻、固定 seed 与指定的 Loadout，headless 驱动完整
   Run，只对外部可观测的行为做断言。同一 seed 加同一串输入必然得到同一个 Run。
